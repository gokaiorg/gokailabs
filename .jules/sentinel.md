## 2026-04-26 - [Strict Content-Security-Policy with External Domain Allowlist]
**Vulnerability:** Missing Content-Security-Policy (CSP), Strict-Transport-Security (HSTS), and Permissions-Policy headers in production configuration (`netlify.toml` and `.htaccess`), increasing the risk of XSS attacks, data injection, and unauthorized use of browser features.
**Learning:** The application heavily relies on external images from multiple domains (e.g., `green.gd`, `art-fate.com`, `amann-inkspiration.com`, `ghostverse.org`, `storage.googleapis.com`) and integrates with Google Tag Manager and Google Analytics. This requires a nuanced CSP that accurately whitelists `img-src` and `connect-src` while still restricting other resources. The CSP also explicitly requires `'unsafe-inline'` for `script-src` and `style-src` per project memory in order for Google Tag Manager to function correctly.
**Prevention:** Implement comprehensive security headers within server configuration files out-of-the-box. Ensure that any future integrations with external services involve updating the CSP carefully rather than relying on an open policy.
