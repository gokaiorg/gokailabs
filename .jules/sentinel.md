## 2024-05-18 - Missing Defense-in-Depth Security Headers
**Vulnerability:** The application was missing defense-in-depth security headers, specifically Content-Security-Policy (CSP), Strict-Transport-Security (HSTS), and Permissions-Policy. This omission increased the attack surface for vulnerabilities like XSS, downgrade attacks, and unauthorized access to browser features.
**Learning:** These missing headers were identified in both `netlify.toml` and `.htaccess`. Implementing a robust CSP required careful configuration to allow legitimate third-party resources (Google Analytics, Tag Manager, and external image CDNs) without being overly permissive. It's crucial to maintain identical security configurations across different hosting environments.
**Prevention:** Implement and enforce a secure baseline configuration for all new web projects, including strict CSP, HSTS, and Permissions-Policy by default. Regularly audit security headers as application dependencies and third-party integrations evolve.
