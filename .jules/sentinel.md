## 2024-05-18 - Missing Strict Security Headers (CSP, HSTS, Permissions-Policy)
**Vulnerability:** The application was missing critical security headers `Content-Security-Policy` (CSP), `Strict-Transport-Security` (HSTS), and `Permissions-Policy` in its server configurations (`netlify.toml` and `.htaccess`), even though it had some basic headers. Missing CSP leaves the application vulnerable to XSS and data injection attacks. Missing HSTS allows potential downgrade attacks. Missing Permissions-Policy allows arbitrary access to sensitive device features.
**Learning:** Security configurations need to be consistently applied across all deployment environments (e.g. Netlify and Apache). We needed a custom CSP that allowed external resources specific to the project, such as external project images, Google Analytics and Tag Manager, while maintaining a strict posture against unauthorized scripts and data connections.
**Prevention:** Implement a secure baseline of HTTP response headers for all new web projects, explicitly defining `Content-Security-Policy`, `Strict-Transport-Security` and `Permissions-Policy`. Regularly audit deployment configurations to ensure these headers are active and correctly scoped.
